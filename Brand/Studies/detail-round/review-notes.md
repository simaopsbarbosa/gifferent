# compact-orbit detail round

all variants preserve the selected compact vertical-loop silhouette. the open crop frame and directional return remain constant; only endpoint spacing and line weight change. black-and-white assets are paired with separate orange layers that can be removed without changing the geometry.

- **01 · balanced ends:** equal arc and tip weights; compact middle gap, stable small-size stroke.
- **02 · breathing room:** arc endpoints stop slightly before the tips; the break may become visible at 16 px.
- **03 · menu-bar weight:** stronger loop strokes and a lighter crop frame; loop reads first, frame second.

all orange treatments use `#ed6a2c` as a sample only. no color value is approved. architect review remains open for endpoint style, loop/frame balance, final orange values and contrast behavior, accessible naming, motion, sound, and usage rules. these are production-ready vector files for review, not a final or approved mark.
