equal-work encoder frame review

spot check only: these are representative still frames at 0, 120, and 239. they do not show full animation, temporal noise, flashing, or flicker. this review does not select a release encoder.

each panel compares one synthetic source frame with the matching decoded GIF frame. open “2× views” for a nearest-neighbor enlargement of the same 640×360 PNG. the source samples were copied to RGB PNG; GIF frames were coalesced to the logical canvas before export. metadata was stripped; pixel content was not resampled.

provenance and settings

  • machine: reference MacBook Air M2, 8 GB, arm64; macOS 27.0.1 build 26A434; Xcode 27.1 build 27A9275; AC power; Low Power Mode off. the benchmark sandbox denied model, chip, and memory probes, and thermal telemetry was unavailable.
  • ImageMagick: 7.1.2-34 Q16-HDRI arm64; SHA-256 324c185d0dead1cf7326e7f87743da28086dde0a00538b96d5cd320ed7543466. optimized path uses -layers Optimize; unoptimized path omits it. both use Floyd–Steinberg, 100% diffusion, 256 colors, identical input ordering and centisecond schedule.
  • ImageIO: legacy helper SHA-256 609a4ba115d69a19db3b23dcd9f3d636196e16bdd53a75201e3e77b6d8e9ac7d. this is not the app's imageio-app encoder.
  • the original GIF paths and benchmark outputs are under ignored Benchmarks/outputs/ directories on the benchmark machine. only these small synthetic PNG frame samples are included here.
